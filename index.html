Cheat sheet

CI: merge small changes often, build and test on every push. CD: deploy automatically once checks pass.

The four DORA metrics: deployment frequency, lead time for changes, change failure rate, time to restore service.

Blue/green: two identical environments; switch traffic when the new one is healthy. Canary: send a small slice of traffic to the new version first.

Infrastructure as code: servers and networks described in files (Terraform, Pulumi, CloudFormation), reviewed and versioned like any other code.

Observability: logs, metrics and traces, so you can ask new questions about a running system.

Idempotent: running it twice has the same result as running it once. This is the property you want in every deploy step.
